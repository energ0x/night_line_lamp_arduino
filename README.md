# Багатофункціональний RGB Нічник на Arduino Uno

Багатофункціональний світильник-нічник з 12 режимами роботи, керуванням через інфрачервоний пульт дистанційного керування, плавними переходами (Fade In / Fade Out), регулюванням яскравості, швидкості анімацій та колірної температури.

---

## 🛠 Апаратна частина

* **Мікроконтролер**: Arduino Uno (ATmega328P)
* **LED модуль**: Keyes LED RGB v2 (8 RGB світлодіодів, спільний анод VCC, активний рівень `LOW`)
* **ІЧ-приймач**: Стандартний інфрачервоний приймач 38 кГц (VS1838B або модуль з набору Arduino)
* **ІЧ-пульт**: Пульт дистанційного керування (протокол NEC)

---

## 🔌 Схема підключення пінів

### Модуль Keyes LED RGB v2:
| Пін модуля | Пін Arduino Uno | Опис |
|---|---|---|
| **VCC** | **5V** | Живлення спільних анодів |
| **R** (Red) | **Pin 9** | Керування червоним каналом (активний `LOW`) |
| **G** (Green) | **Pin 10** | Керування зеленим каналом (активний `LOW`) |
| **B** (Blue) | **Pin 11** | Керування синім каналом (активний `LOW`) |
| **LED1 .. LED8** | **Піни 1 .. 8** | Вибір активного світлодіода для мультиплексування (активний `LOW`) |


> [!NOTE]
> **Pin 1 (TX)** в коді виділено суто як дискретний вихід для **LED1**. Апаратний `Serial UART` повністю вимкнено, щоб уникнути конфліктів та мерехтіння діода.

### ІЧ-приймач (IR Receiver):
| Пін датчика | Пін Arduino Uno |
|---|---|
| **OUT / S / DATA** | **Pin 12** |
| **VCC / +** | **5V** |
| **GND / -** | **GND** |

## 🎮 Керування з пульта

### Загальні кнопки:
* **[ OK ]** — **Увімкнення / Вимкнення світильника**. 
  - Плавне розгорання (Fade In) при увімкненні.
  - Плавне згасання (Fade Out) при вимкненні.
  - Зберігає останній активний режим та всі його налаштування.
* **[ ▲ ] / [ ▼ ]** — **Регулювання яскравості** (8 рівнів від 10% до 100% у всіх режимах).
* **[ ◄ ] / [ ► ]** — **Регулювання швидкості** (для анімацій 4, 8, 9, 0) або **колірної температури** (для режиму `#`).
* **Утримання кнопок (> 300 мс)** — при швидкому натисканні (< 300 мс) виконується 1 крок; якщо затиснути кнопку довше 300 мс — вмикається плавне безперервне регулювання.

## 🌈 12 Режимів роботи нічника

| Кнопка | Режим | Опис роботи |
|---|---|---|
| **[ 1 ]** | **Нейтральне біле світло** | Каліброване природне біле світло (~4000K) |
| **[ 2 ]** | **Тепле світло** | Затишне тепле бурштинове/лампове світіння (~2000K) |
| **[ 3 ]** | **Холодне світло** | Денне/холодне біле світло з легким блакитним тоном (~6000K) |
| **[ 4 ]** | **Bouncing Comet (Комета-маятник)** | Яскраве ядро комети пробігає рядком, відбивається від країв стрічки (0 $\leftrightarrow$ 7), залишаючи короткий плавний хвіст та змінюючи колір при кожному ударі |
| **[ 5 ]** | **Червоне світло** | Статичний насичений червоний колір (R:255, G:0, B:0) |
| **[ 6 ]** | **Зелене світло** | Статичний насичений зелений колір (R:0, G:255, B:0) |
| **[ 7 ]** | **Синє світло** | Статичний насичений синій колір (R:0, G:0, B:255) |
| **[ 8 ]** | **Веселка (Rainbow Wave)** | Хвильовий плавний спектральний градієнт по 8 світлодіодах (20 швидкостей) |
| **[ 9 ]** | **Синхронне переливання** | Всі діоди одночасно плавно змінюють колір по спектральному колу (20 швидкостей) |
| **[ 0 ]** | **Плавне дихання 9 кольорами** | Почергова плавна поява та згасання 9 кольорів: червоний, зелений, синій, фіолетовий, жовтий, ціановий, рожевий, білий, оранжевий (20 швидкостей) |
| **[ * ]** | **Інтерактивне введення RGB-коду** | Ручне введення коду довільного кольору (RRRGGGBBB) |
| **[ # ]** | **Регульоване біле світло** | Плавне налаштування температури білого кнопками **[ ◄ ]** (тепліше) та **[ ► ]** (холодніше) у діапазоні **1000K – 10000K** (46 кроків по 200K) |

---

## 🎨 Детально про режим вибору кольору [ * ]

1. **Курсор (0 цифр)**: При вході в режим 1-й світлодіод м'яко дихає теплим світлом як текстовий курсор.
2. **Прогрес-бар з живим прев'ю (1..8 цифр)**: Кожна введена цифра засвічує наступний діод. Усі активні діоди в реальному часі відображають змішаний колір, який формується.
3. **Стирання цифри (Backspace)**: Натискання кнопки **[ # ]** видаляє останню цифру та повертає прогрес-бар на крок назад.
4. **Фінальна пульсація (9 цифр)**: Після вводу 9-ї цифри всі 8 світлодіодів починають плавно дихати готовим кольором.
5. **Підтвердження**: Натисніть **[ * ]** або **[ OK ]** для фіксації кольору.

---

## ⚡ Плавні переходи (Fade In / Fade Out)

Усі перемикання режимів, увімкнення та вимкнення відбуваються через вбудований неблокуючий плавний перехід без затримок `delay()` — світлодіоди м'яко згасають і плавно набирають яскравість нового режиму.
